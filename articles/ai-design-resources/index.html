AI × 設計資源精選：素材、工作流與工具

先抓重點

  • 素材類最實用：DESIGN.md 把 70+ 大廠設計系統做成一份 Markdown，丟給 AI 就能照大廠風格做。
  • 工作流類：用 MCP 讓 AI 直接讀真實網站的 CSS 來仿版，比憑空生成準得多。
  • 工具類挑選有據：多 agent 終端、無人值守編碼、開源剪輯都值得看；但『持久記憶』類插件品質參差，引用要謹慎。

一、設計素材與系統

DESIGN.md — 把大廠設計系統打包成一份檔案

有人逆向了 Stripe、Vercel、Linear、Notion、Apple、Tesla 等 70+ 大廠的設計系統，做成一份 Markdown（含完整 design token：色彩、字體、間距、組件、動效），MIT 授權。

用法：下載後改名成 DESIGN.md 丟到專案根目錄，然後叫 AI「按 DESIGN.md 的規範做一個設定頁」，它就會照該大廠風格產出。

提醒：它是風格指南，不是組件庫——互動細節還是要自己定義；金融、醫療等強監管行業別直接照搬。

用 MCP 直接「仿版」真實網站

與其讓 AI 憑空生成（然後給你 AI slop），不如讓它讀真的網站。透過 MCP，AI 能即時檢查任一網址的 HTML/CSS，提取它的布局、色彩、字體、間距、組件，用真實設計系統當參考。

有個叫 aidesigner.ai 的 MCP 工具就是做這個，給 coding agent「讀懂設計」的能力。

二、工作流與編碼工具

工具做什麼適合誰
kookymacOS 終端整合工作區，橫竪分屏、一鍵啟動多個 AI agent（Claude Code／Codex／Gemini CLI），右鍵選取直接提問想同時管多個 AI 助手的人
gnhf（Good Night, Have Fun）讓 Claude Code／Codex 無人值守自動跑：自動 commit、報錯自動回滾重試、跨輪記筆記、連續失敗就退避省 token想讓 AI 掛著自己跑的人
Clypra開源影片編輯器（Tauri＋React），本地免費復刻剪映 Pro，FFmpeg 驅動、零聯網零水印、MIT需要免費剪輯又重隱私的人

小提醒：這類工具更新很快，社群回覆也常點出更成熟的替代品（例如剪輯有 OpenCut／Shotcut／Kdenlive）。挑工具時順手看一下留言區的實戰評價。

三、發掘更多小工具

  • macmenubar.app：一個專門策展 Mac 選單列（menubar）App 的目錄站，按分類（生產力、設計、AI、剪貼簿、系統監控）瀏覽。想找常駐在選單列的小工具，從這裡挖很快。

引用要謹慎的：持久記憶類插件

有款叫 claude-mem 的 Claude Code「持久記憶」插件很紅（近 5 萬星），號稱永不觸及上下文限制。但負評不少：有人回報記憶體溢出、疑似大量帳號帶推廣，也有人直言「持久記憶不就是一個 Markdown 的事」。

收錄它是要提醒你：AI 圈很多「爆紅工具」是行銷推起來的，星數 ≠ 品質。看到再厲害的宣稱，先查留言區的實際使用回饋再決定要不要用。
