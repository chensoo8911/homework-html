Claude Skills 是什麼？用資料夾擴充 AI 的能力

先抓重點

  • Skill 就是一個資料夾，裡面放『指令＋腳本＋資源』，讓 Claude 遇到特定任務時自動載入、表現更好。
  • 核心是一份 SKILL.md 檔，開頭只要填 name 和 description 兩欄，Claude 就知道何時該用它。
  • 官方已內建文件類 skill（docx／pdf／pptx／xlsx），也能自己做品牌、設計、自動化用的 skill。

一句話：Skill 是「給 AI 的工作手冊」

你可以把 Claude Skill 想成：一份專門教 Claude 做某件事的資料夾。

裡面放三種東西：

  • 指令（怎麼做這件事的步驟與原則）
  • 腳本（可執行的小程式）
  • 資源（範本、參考檔案）

當你叫 Claude 做某個任務，它會動態載入對應的 skill，照手冊做，結果就比「憑空發揮」穩定、專業得多。

核心：一份 SKILL.md

每個 skill 都有一份 SKILL.md。它的開頭（YAML frontmatter）只需要兩欄：

name: 這個 skill 叫什麼
description: 它能做什麼、什麼時候該用

就這麼簡單。description 寫得好，Claude 才知道「這個任務該不該叫出這個 skill」。剩下的正文就是給 Claude 看的操作手冊。

這其實跟你在公司寫 SOP 給新人看是一樣的道理——把「怎麼做才對」寫下來，執行者照做就不會亂。

官方內建的 skill 範例

Anthropic 官方 repo 裡最實用的是文件類 skill，它們實際驅動了 Claude 生成檔案的能力：

Skill做什麼
docx產生 Word 文件
pdf產生／處理 PDF
pptx產生簡報
xlsx產生 Excel 表格

除此之外還有創意設計、測試網頁 app、生成 MCP server、企業溝通／品牌等範例。

怎麼裝來用

  • Claude Code：先加入市集，再裝套件包

    /plugin marketplace add anthropics/skills

    然後安裝 document-skills（文件類）或 example-skills（範例類）。

  • Claude.ai：付費方案已經內建這些 skill，不用自己裝。

repo 目錄結構也很清楚：./skills（各個 skill）、./spec（Agent Skills 規範）、./template（自己做 skill 的範本）。

為什麼設計師該懂這個

因為你可以把自己的設計流程、品牌規範、常用工作法寫成 skill，讓 AI 每次都照你的標準做。下一篇我們就看一個專門教 AI「抓設計品味」的開源 skill。
