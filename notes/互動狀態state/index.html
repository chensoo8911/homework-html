互動狀態 State（hover／active／focus／disabled）

同一顆元件（按鈕、連結、輸入框…）在不同時機會長不一樣，這些「時機」就叫互動狀態（State）。目的是給使用者回饋：告訴他「這裡是活的、可以操作」。

四個基本狀態

狀態時機常見表現
Hover滑鼠移上去、還沒按下變色／浮起／出現陰影
Active正在按下的當下下沉／變深色
Focus被選中（用 Tab 鍵跳到、或點進輸入框）外框高亮（focus ring）
Disabled停用、不能點變灰、游標變禁止符號

白話重點

  • 這一組就是「一顆按鈕的四種臉」，是同一個元件的不同時機，不是四個不同元件。
  • 回饋感是 UI 好不好用的關鍵：滑鼠移上去有反應，使用者才敢點。
  • 手機沒有 hover（觸控沒有「移上去但還沒按」這個階段），所以重要資訊不能只靠 hover 傳達，不然手機使用者看不到。
  • Focus 很重要別省：用鍵盤（Tab）操作、或無障礙需求的人，全靠 focus 外框知道現在跳到哪。設計時不要為了好看把 focus ring 拿掉。

設計師比喻

像實體按鈕：手指靠近會亮一下（hover）、按下去會凹陷（active）、被電流選中會亮邊（focus）、沒接電就是暗的按不動（disabled）。四種狀態＝告訴你這顆按鈕現在「活著還是死著、被碰到還是被按下」。
