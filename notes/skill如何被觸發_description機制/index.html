Skill 如何被觸發？description 機制

拆自「Skill與自動化全解」Part 2

兩者都是 Claude 自己判斷，不是要打精確指令才動。判斷依據＝每個 skill／plugin 的 description（描述＋觸發詞）。

方式例子說明
自然語言（自動判斷）說「幫我發版」Claude 讀到描述裡有「發版」→ 自動觸發
手動明確叫（斜線）打 /command-push直接指定，不靠判斷

比喻：像 Figma 的 auto layout——不用手動排每個元素，它依你設好的規則自動判斷。skill 的 description 就是那組規則。

👉 觸發詞是 skill 的靈魂。描述清楚、觸發詞明確 → 幾乎每次都判斷得到；描述模糊 → 該觸發時可能沒觸發。建 skill 時最該花心思的就是這段。
