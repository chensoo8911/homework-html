什麼是 Agent

拆自「自動化名詞關係總圖」，只留「什麼情況才算 agent」這塊

核心判準：能「自己決定下一步」而且「會動手做」，才叫 agent。 只會回答問題的 AI ≠ agent；只會照死腳本跑的程式也 ≠ agent。

四個條件（②＋④是關鍵）

條件白話
① 給的是「任務」不是「問題」「幫我做完名片」而非「名片尺寸多少」
② 自己拆步驟自己決定先做什麼、後做什麼
③ 會動手用工具讀檔、跑命令、呼叫 MCP、改檔案
④ 看結果會調整做錯會自己再試一次

對照

東西是 agent？為什麼
Claude Code 跑完整名片流程✅ 是自己拆步驟、動手改檔、跑錯重試
ChatGPT 回答「padding 是什麼」❌ 不是只問答一句，沒動手沒任務
一個 script❌ 不是照死步驟跑，不會判斷
/uiai-learn skill🔸 半個skill 是「做法包」，執行它的 Claude 才是 agent
Figma MCP❌ 不是只是插頭，自己不決策

skill / workflow / MCP / script 都是「工具或說明書」，agent 是那個「拿著它們幹活、還會自己判斷」的執行者。 同一個 Claude，單純問答時只是「AI 助手」，一旦開始自己拆任務＋動手改檔，就升格成「agent」。差別在它當下有沒有在自己決策＋動手。
