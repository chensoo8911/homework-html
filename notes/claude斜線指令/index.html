AI與Claude工具

Claude Code 的 /指令（斜線指令）入門

一句話總結：斜線指令＝遙控器上的快捷鍵。打一個 / 跳出選單，按下去就叫它做特定的事，不用打一長串說明。

💡 聯想記憶法：/ 想成「斜斜地比手勢叫服務生」——你一比，選單就來了。

🌟 一定要先會的 5 個

指令白話功能什麼時候用
/help求救選單（help＝幫助）忘記有哪些指令時，打它就對了
/clear清空對話（clear＝清乾淨）聊太久、想重新開始一個乾淨話題
/init幫專案建一份說明書第一次在一個資料夾用 Claude Code 時
/model換腦袋（model＝模型）想切換不同強度的 AI
/cost看花了多少錢（cost＝花費）想知道這次用了多少額度

🔧 之後會用到的幾個

指令白話功能
/memory編輯它的「長期記憶」筆記
/compact把長對話壓縮成重點（省空間）
/mcp管理外掛工具（像 Figma 插件就是 MCP）
/config調設定
/login、/logout登入／登出帳號

🚀 進階好用指令（熟一點再玩）

指令白話功能什麼時候用
/resume接續舊對話（resume＝接著做）昨天聊到一半，今天想從原處繼續
/agents管理小幫手（agent＝代理人）想叫專門的 AI 分身做特定工作
/review幫你審查程式碼／改動寫完東西想請它檢查
/bug回報問題給官方Claude Code 怪怪的、想反映
/doctor健康檢查（doctor＝醫生）安裝怪怪的、想看哪裡沒裝好
/vim開 Vim 編輯模式習慣 Vim 鍵位的人才需要
/terminal-setup設定終端機按鍵想讓 Enter 換行更順手
/add-dir加入其他資料夾想讓它同時看好幾個專案夾
/insights產生「使用習慣洞察報告」，分析最近的對話紀錄（做了什麼、卡在哪、能怎麼改善）想回顧自己這陣子怎麼用 Claude Code、找改善方向時

💡 聯想記憶法：resume 跟「履歷」同字，但這裡是動詞「re-（再）+ sume（拿起）＝再拿起來繼續做」。

🧰 補充小記（Ghostty ＋ 復原）

指令／按鍵白話功能
/rewind復原被改動的 md（吃 file-history，30 天內有效）
Ghostty ctrl+O檢視目前狀態
