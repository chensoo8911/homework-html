系統與工具流程

scp／rsync／Taildrop 怎麼選

[!tip] 一句話記住 問自己：這個資料夾我還會再傳第二次嗎？ 會 → rsync，不會 → scp。要用滑鼠拖拉、不想打指令 → Taildrop（但到不了 WSL）。

scp（安全複製）

走 SSH 連線把檔案從一台電腦複製到另一台，跨電腦版的「複製貼上」。

scp 稿子.pdf wsl:~/                   # Mac → 遠端主機的家目錄
scp wsl:~/output.jpg ~/Downloads/     # 遠端 → Mac
scp -r 資料夾 wsl:~/                   # -r = 整個資料夾

wsl: 是 ~/.ssh/config 裡設好的主機別名。

特性：每次都整份重傳（不比對差異）、傳完就結束、指令簡單好記。

rsync（遠端同步）

讓兩台電腦的資料夾內容一致，傳之前先比對，只傳有差異的部分。

rsync -av ~/我的專案/ wsl:~/我的專案/

-a = 保留檔案日期與權限，-v = 顯示傳輸過程。

特性：第一次跟 scp 差不多慢，第二次起超快（沒改的檔跳過）；斷線可續傳；選項多容易記錯。

[!warning] 結尾斜線 / 地雷

  • rsync -av 資料夾/ 目的地/ → 把資料夾「裡面的東西」放進目的地
  • rsync -av 資料夾 目的地/ → 把「資料夾本身」放進去，變成 目的地/資料夾/

少一條斜線就多一層資料夾。不確定時加 -n（只演練不真傳）先看結果。

三者比較

scp / rsyncTaildrop
檔案送到哪可指定任何路徑只能進對方「下載」資料夾，之後要自己搬
能不能自動化可寫進腳本／排程／讓 AI 代勞只能人手動拖拉
只傳差異rsync 可以每次整份重傳
要打指令要不用

關鍵限制：Taildrop 只到得了 Windows，到不了 WSL——因為 Tailscale 裝在 Windows 上，檔案會落在 C:\Users\ADMIN\Downloads\，要給 WSL 用還得從 /mnt/c/... 再搬一次。而 scp wsl:~/ 是直接送進 WSL 家目錄，一步到位。

另一個關鍵：要讓 AI 助理幫忙傳檔，只能用 scp／rsync，Taildrop 是 GUI 操作，AI 碰不到。

💡 實測數據（2026-09-17，Mac ↔ MSI 走 Tailscale）

50MB 檔案傳輸耗時 17.8 秒，約 2.8 MB/s。兩台不在同一 Wi-Fi 所以走 Tailscale 中繼；若接同一個 Wi-Fi，Tailscale 會自動改直連，速度會快數倍，不用改設定。

比雲端硬碟快的原因：雲端要跑兩趟（上傳到雲端 → 從雲端下載），scp 只跑一趟，且不占雲端空間、不用等同步。
