Homebrew Mac 軟體小幫手

一句話總結：Homebrew 是 Mac 上的「軟體小幫手」，打一句指令就幫你自動下載、安裝、設定好工具，不用自己上網東找西找。

💡 聯想記憶法：Homebrew（念：home-bru，原意「自家釀的啤酒」🍺）＝「自己在家輕鬆搞定」的感覺。

🌟 用「點外送」來理解

沒有 Homebrew有 Homebrew
想裝工具要自己找官網、下載、解壓縮、設定…很累打一句指令，它自動幫你找好、裝好、設定好
像自己出門買菜煮飯 🍳像用 App 點外送，講一聲就送到家 🛵

🔑 為什麼我會用到它

工具鏈裡的 Ghostty（終端機）、Claude Code 這類工具，最簡單的安裝方式常常就是透過 Homebrew。

brew install ghostty

翻譯：「嘿 Homebrew，幫我裝 Ghostty」→ 它就自己搞定了。
