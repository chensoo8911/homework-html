AI與Claude工具 記於 2026-07-16

非工程師從零安裝 Claude Code 教學

來源 YouTube 影片整理，2026-07-16 記錄

核心示範：完全不懂寫程式，也能把 Claude Code 設定成真正會做事的貼身助理。

1. AI 工具三階段比喻

階段比喻能做什麼
ChatGPT / Gemini圖書館只能問答
一般 Agent 工具外包整理師處理檔案分類、簡單行事曆／信件
Claude Code貼身管家自帶工程團隊、記得脈絡、能授權操作其他系統、外掛工具近乎無限

2. 推薦工具

工具用途備註
Claude Code（CC）主程式官網 claude.com 或 claude.ai 下載安裝，需付費訂閱（建議先訂 Pro 每月 20 美金，額度不夠再升 Max）。⚠️ Google 搜尋排前面的「贊助商」結果常是釣魚網站，長相跟官網一樣，勿點，務必認清官方網址。
CMUX第三方終端機工具取代原生 Terminal 難用體驗（支援多分頁、分割視窗、滑鼠選取自動複製）。
Firecrawl（MCP）補強網頁爬取適合一般網站，免費方案每月可爬 500 篇文章。
Playwright（MCP）補強網頁爬取適合社群媒體這類靠 JavaScript 動態渲染的網站（Firecrawl 這類爬不動時用它）。

3. 上手技巧

3-1　建立 CLAUDE.md

進去第一件事就是叫它「幫我建立 CLAUDE.md 記住我的偏好」，它會反問問題來建檔；也可以先用任一 AI 工具產生一段脈絡摘要文字再貼給它建檔。

CLAUDE.md 的角色、疊加機制細節見 Claude的md檔案家族、Claude_Skill儲存與指示疊加，這裡只記「怎麼開口叫它建」。

3-2　專屬工作資料夾

不要放系統預設位置，另開資料夾，用 Command+Shift+C 複製路徑，跟 Claude Code 說「幫我移動到這個路徑」，讓它自己執行 cd 指令，不用自己學指令。

3-3　把自己當顧客

遇到操作卡關直接問 Claude Code，不用自己 Google 或硬記指令。

3-4　CC 快捷鍵別名（alias）

設定打「cc」兩個字就自動進到專案路徑並啟動新版對話模式（No Flicker，畫面更順、支援滑鼠選取自動複製）。可以把現成 GitHub／Notion 設定文檔網址丟給它說「幫我讀懂並安裝設定」。

3-5　權限模式（Permission Mode）＝ AI 助理的四種操作模式（自主權由低到高）

白話理解：這四種模式就像「你放手讓助理做多少事」的刻度，從你逐字審稿，到你直接交辦放著跑。

模式AI 自主權白話說明好處適用情境
Manual（手動／Default）0%每一步都要你按「允許」才會動手絕對安全、完全掌控細節處理極度重要的核心檔案、高風險操作
Plan（計畫）約 30%AI 先提出執行計畫，你審查修正後才放行確保大方向不跑偏，避免白做工大型專案、結構複雜需要架構規劃的任務
Accept Edits（接受修改）約 60%AI 直接動手改，你事後檢視被改動的結果流暢的寫入體驗，省去頻繁確認連續除錯（debugging）或文章潤飾
Auto（自動／Bypass Permissions）約 95%下指令後放手，等結果出爐再看省時省力、完全自動化跨步驟執行長時間運行、繁瑣多步驟的自動化任務（建議在隔離安全環境）

用 Shift+Tab 快速切換，或打 /config 看完整設定（含 Model 選擇：一般用 Sonnet 省額度，需要最強百萬字上下文才選頂規模型）。典型用法：先用 Plan Mode 確認架構，再切到 Accept Edits 或 Auto Mode 開始執行。

記錄日期：2026-07-23（原表格為 2026-07-16 簡版，此次擴充自主權比例／好處／適用情境對照）

👉 完整六等級（含 Don’t Ask、Bypass Permissions 兩種進階模式）見 Claude權限模式六等級。

3-6　防護規則（黑名單）

可以把現成 GitHub 開源防護文檔丟給 Claude Code，讓它自動設好「避免誤執行危險指令（如刪除、系統控制）」的規則；同時它會建議選哪個權限模式較合適。

3-7　給它工具讓它變更強（MCP）

Claude Code 跟一般 AI 最大差別是可以裝外掛工具（MCP）擴充能力。遇到爬取 JS 動態渲染網站（如社群媒體）卡住時，額外裝 Firecrawl／Playwright 這類 MCP 補強。

3-8　重要規則要求它寫進 CLAUDE.md

新設定的規則（例如爬蟲原則）要主動要求它記錄進 CLAUDE.md，不然下次開新對話會忘記，要養成習慣確認它真的寫了。
