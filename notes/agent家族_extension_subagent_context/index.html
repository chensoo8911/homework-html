Agent 家族：extension／subagent／context

拆自「自動化名詞關係總圖」，只留「agent 家族」這塊

extension（延伸套件）

裝在編輯器裡的視覺化面板，讓你「用眼睛看」AI 對檔案做了什麼。 ⚠️ 別跟 plugin 混：plugin 是「給 Claude 加能力的包」，extension 偏「給你看的介面外掛」。

subagent（子代理）

主 agent 派出去幫忙的分身，做完只把「結論」回報。

  • 好處①分工並行：一次派多個去查不同東西，快。
  • 好處②省 context：子代理自己讀一堆檔（佔它的桌面），只回報結論給主管。
主 agent（主管）
   ├── subagent A → 查資料 → 只回報結論
   ├── subagent B → 掃資料夾 → 只回報結論
   └── subagent C → 驗證答案 → 只回報結論

context（上下文 / 脈絡）— 最重要

AI 當下「腦中記得的所有東西」——這串對話、讀過的檔、系統規則，全加起來。

  • 比喻：像攤開的桌面，攤在桌上它才記得。
  • 有上限（context window）：桌面就這麼大，塞太滿會擠掉舊的 → 這就是長對話 AI 會「忘記」前面的原因。

context 是 agent 的「桌面大小」，subagent 是「派人去別的桌面幹髒活、只回報結論」來省你的桌面。
