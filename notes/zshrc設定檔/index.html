系統與終端機

~/.zshrc

是什麼：終端機（Terminal / Ghostty）每次開啟時，自動讀取執行的個人設定檔。

拆解

  • ~ = 家目錄（你的使用者資料夾）
  • .zshrc = 隱藏檔（點開頭 Finder 預設不顯示），zsh 是終端機殼層（shell）名稱，rc 是 run commands 縮寫

裝了什麼

  • 自訂捷徑（alias）：例如打「小G」其實是叫某段指令去跑
  • 環境變數：例如 GEMINI_API_KEY（Gemini 金鑰）、BRAIN_DIR（三劍客落檔資料夾）
  • 自訂函式：例如 _xiaog（小G背後真正在跑的邏輯）

比喻

像 Illustrator 開啟時自動載入的「工作區偏好設定」（自訂快捷鍵、面板排列、預設單位）——.zshrc 是終端機版的那份偏好設定，每次開新視窗都會重新套用一次。

實務關聯

三劍客（小G/小L）的呼叫指令就是寫在這個檔案裡的 START/END 標記區塊。維護時要注意本機這個區塊跟對應 repo 範本應保持「只差金鑰與路徑等私人值」的最小差異，方便用 diff 檢查有無漂移。

相關

  • 跟 cwd（目前工作目錄，見 網頁大詞彙）不是同一件事：.zshrc 是「每次開終端機都會執行的設定檔」，cwd 是「當下終端機停在哪個資料夾」——一個是「開機時做什麼」，一個是「現在人在哪」。
  • GitHub 帳號切換（已移到 ~/Claude/備忘錄）：gh-sv / gh-me / gh-who 這些捷徑就是裝在 .zshrc 裡的其中一種內容。
