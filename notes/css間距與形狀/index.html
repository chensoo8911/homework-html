CSS 間距與形狀

記錄日期：2026-07-09 網頁排版最基礎的兩件事：元件之間怎麼留白、元件長什麼形狀。

本篇目錄：padding 內距 · padding vs margin · 間距三兄弟 margin/padding/gap · 盒模型 Box Model · pill 膠囊鈕（形狀相關的內容也在這篇，別漏看）

padding（內距）

元件「內容」跟「邊框」之間的內部空隙。

  • 設計師比喻：像便當盒裡，菜跟盒壁之間留的緩衝空間。
  • 你在 Figma 做按鈕，文字外圍留的那圈呼吸空間就是 padding。
┌─────────────────┐  ← 邊框（border）
│   ↕ padding     │
│  [   文字   ]   │  ← 內容（content）
│   ↕ padding     │
└─────────────────┘

padding vs margin（一定要分清楚）

padding（內距）margin（外距）
位置邊框內側，內容周圍邊框外側，元件之間
作用內容的呼吸空間跟隔壁元件的距離
一句話往內撐往外推

間距三兄弟：margin / padding / gap（初學最常搞混）

元件之間的間距，其實沒有單一官方詞。最常聽到的講法：gap（排版容器裡子元件的縫）、spacing（統稱）、whitespace／留白。實作上要調「元件之間」的距離，用的是 gap。

三兄弟一次分清楚：

是什麼一句話
margin（外距）盒子外面推開別人的距離對外
padding（內距）盒子內裡撐開內容的距離對內
gap用 Flexbox／Grid 排版時，子元件之間的縫排版容器裡、元件與元件之間
  • 設計師比喻：padding 像名片裡「文字到卡片邊緣」的安全距離；margin 像「兩張名片擺一起要留的間隔」；gap 像把一整排名片放進同一個框裡，框幫你把每張之間的縫都撐一樣寬。
  • 記法：margin 對外、padding 對內、gap 是排版容器裡子元件之間。要做「元件之間」的間距 → 用 gap。
gap：一整排卡片放進同個容器，容器統一撐開每張之間的縫
┌───────────────────────────────┐  ← 容器（Flexbox / Grid）
│ [卡片] ← gap → [卡片] ← gap → [卡片] │
└───────────────────────────────┘

盒模型（Box Model）

理解排版的地基：每個元件都是一個盒子，由內到外＝

content 內容 → padding 內距 → border 邊框 → margin 外距

┌─ margin（外距，跟隔壁的距離）─────────┐
│  ┌─ border（邊框）──────────────┐  │
│  │  ┌─ padding（內距）────────┐  │  │
│  │  │      content 內容      │  │  │
│  │  └───────────────────────┘  │  │
│  └─────────────────────────────┘  │
└───────────────────────────────────┘

排版就是在調這四層。看懂盒模型，之後所有間距問題（為什麼推不開、為什麼擠在一起）都能拆開來想。

pill（膠囊／藥丸鈕）

兩端是全圓角的長條形狀，外型像藥丸／膠囊，所以叫 pill。

  • 常見於：tag 標籤、篩選鈕、狀態徽章（例：熱門、新品）。
  • 做法：圓角（border-radius）開很大，大到左右兩邊變成半圓。
  • 對照：一般按鈕是「小圓角方形」，pill 是「圓到底的長橢圓」。
一般按鈕： [  按鈕  ]   ← 小圓角
pill：    (  標籤  )   ← 兩端全圓
