CLI 與 MCP 與 Agent 的差別

拆自「自動化名詞關係總圖」第四節，單獨拆出方便查找「MCP 跟 CLI 差在哪」

會這樣想，多半是因為 Claude Code 剛好三個都沾，就把它們畫上等號。但其實三者是各自獨立的維度。

CLI 只是一種「操作方式」，本身不含 agent、也不含 MCP。 CLI ＝ 用打字操作程式（相對於滑鼠點），是個「形式／通道」。

反證：一堆 CLI 工具跟 AI 完全無關——

CLI 工具有 agent 嗎？有 MCP 嗎？
git／cp／brew❌❌
Claude Code✅✅

正確說法：Claude Code 是「一個用 CLI 形式呈現的 agent，而且它會用 MCP」。三個維度剛好同時具備：

維度問的是Claude Code
CLI你怎麼操作它？打字（不是滑鼠 App）
Agent它會不會自己幹活？會（自己拆任務、動手）
MCP它能不能連外部軟體？能（Figma、Illustrator）

比喻：CLI 像「用鍵盤打字下單」這個動作。你不會說「打字 ＝ 主管 ＋ 電話」——打字只是下單方式；接單的是不是會思考的主管（agent）、他有沒有對外電話（MCP），是另外兩件事。同一種「打字下單」，後面接的東西可以差很多。
