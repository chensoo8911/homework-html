🎨 設計師一眼速查（對你的意義）

名詞角色比喻對設計師的意義

Agent工作室的主管幫你處理繁瑣的設計工序
Prompt設計需求單（Brief）與 AI 溝通品質的決定性關鍵
Token任務計程車費衡量任務成本與效率的指標

CLI快速指令通道比滑鼠更快的自動化執行
Extension助理的儀表板即時查看 AI 對檔案的修改

兩個世界關係總圖

這些詞其實分屬兩個世界，中間有一座橋。

一邊是「你對電腦下令」的世界，一邊是「你對 AI 下令」的世界，SOP 是兩邊都想自動化的那份「人類做事步驟」。

┌─────────────────────────┐   ┌─────────────────────────┐
│   🖥️ 對電腦下令的世界      │   │   🤖 對 AI 下令的世界       │
│  （終端機 / 打字操作）      │   │  （Claude / 自動化）        │
├─────────────────────────┤   ├─────────────────────────┤
│  CLI   ← 打字操作的「方式」 │   │  prompt ← 你給 AI 的需求單  │
│  shell ← 接收命令的「程式」 │   │  agent  ← 會思考+行動的 AI  │
│  bash  ← shell 的一種       │   │  skill  ← 打包好的一套做法  │
│  command ← 你打的「一行」   │   │  workflow ← 多步驟串成流程  │
│  script  ← 多行 command 存檔│   │  plugin ← 把上面全打包成一包│
│                           │   │  MCP    ← 連到外部軟體的插頭│
└───────────┬─────────────┘   └───────────┬─────────────┘
            │                             │
            └──────────► SOP ◄────────────┘
               人類的「標準做事步驟」
        （script 是它的程式版，skill 是它的 AI 版）

🖥️ 左邊：對電腦下令（由小到大）

詞是什麼比喻
command你打的一行指令對電腦說的「一句話」
CLI用「打字」操作程式的介面方式（相對於滑鼠點）快速通道
shell真正接收並執行命令的那個程式聽命令的櫃檯人員
bashshell 的其中一種（Mac 另有 zsh）櫃檯人員的一個品牌
script把很多 command 存成一個檔、一次跑完懶人包按鈕

關係：透過 CLI 這種方式，把 command 打給 shell（例如 bash）執行；重複的就寫成 script。

🤖 右邊：對 AI 下令（一層包一層）

詞是什麼關係
prompt你給 AI 的自然語言需求最小單位，一句話
agent會讀 prompt、自己決定行動的 AI讀你的 prompt 幹活
skill把「一套做法／SOP」打包給 agent 一鍵觸發觸發詞一喊就照做
workflow把多步驟／多 agent 串成固定流程比 skill 更管「順序」
MCP讓 agent 連到外部軟體的「插頭」Figma／Illustrator MCP
plugin把 skill＋設定＋MCP 整包成可安裝分享最外層包裝盒，plugin ⊃ skill

💡 這一切的地基是 LLM（大型語言模型）＝那顆被訓練來「理解＋生成文字」的大腦（Claude／GPT／Gemini 都是 LLM）。 agent ＝ LLM（大腦）＋ 工具（MCP 等）＋ 決策迴圈；prompt 是餵給它的輸入、token 是它的運算單位、context 是它腦中攤開的桌面。光一顆 LLM 只會聊天，裝上手腳跟「做錯再試」的迴圈才升格成 agent。

🌉 中間的橋：SOP

  • SOP = 人類寫的「標準作業流程」（食譜），不是程式也不是 AI。
  • 交給電腦自動化 → 寫成 script。
  • 交給 AI 自動化 → 打包成 skill。
  • 所以同一個流程可以同時有 SOP.md（人看的）和 skill（AI 執行的）＝同一份步驟、兩種自動化。
